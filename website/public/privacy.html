Your data.
Clear boundaries.

This website introduces Metric Owl. It is separate from the monitoring application you run on your own server.

This website

We do not load third-party analytics, advertising pixels, third-party fonts or tracking cookies. Product screenshots are static images with illustrative data. Viewing them does not connect you to a live server or require an account.

The web server may record standard request information, including your IP address, request time, requested path, browser information, referrer and response status, for operation and troubleshooting.

Contact by email

Contact links open your email application. If you email services@metricowl.cloud, your address and message are handled by our email provider and used to respond to your request. Do not send credentials, private logs or other sensitive server data unless separately agreed through an appropriate channel.

The self-hosted application

The application, administrator account, web dashboard, metrics and SQLite history run on your own server. HTTPS access connects your browser directly to that installation. This website is not a central account or history store and exposes no shared dashboard or login.

Connections you choose to enable

  • Email: your configured SMTP provider, or optional notification relay, receives the recipient address, server alias, event or report summary and selected measurements needed for delivery. Recipients must be verified. Raw logs are not email attachments.
  • Server AI chat and incident analysis: the question, limited recent conversation and bounded monitoring context are sent to the AI provider you connect when you explicitly send a chat question. Optional automatic incident analysis sends eligible event evidence only when enabled. Evidence is redacted before transmission; saved API keys remain encrypted on your server. Chat conversation stays in the page session. Redaction reduces exposure; review which sources you allow the application to read. Your provider’s own terms apply.
  • MCP: an authorized client can retrieve information within its configured read scopes. That client’s configured model, including a cloud model, interprets the returned data under its own terms and billing. MCP does not call the server’s saved Grok or other provider connection.
  • Webhooks: enabled destinations receive signed event or report data. A destination response cannot trigger a server command.

Questions

For questions about this website or a message you have sent, contact services@metricowl.cloud.
