Do I need an AI key to use Metric Owl?

No. Measurements, history, rules and incidents work without an AI provider. You can add your own key for optional incident analysis. Provider availability, limits and charges depend on your account.

Does Metric Owl change anything on my server?

Monitoring and MCP tools observe the sources you permit. They cannot run shell commands or change your applications. Installation creates Metric Owl’s own service and files; the app writes its own settings, history and notification queue.

Can it tell me when my entire server goes offline?

A program running on an offline server cannot send an alert from that server. Independent outage monitoring is planned for Pro. Restart detection after a server comes back is being added to the free edition.

Will I need to install a mail server?

No mail server is required on the monitored machine. Connect your own SMTP provider and verify your recipient. A notification relay is optional. Connection testing checks the provider; a separate test email lets you check your mailbox.

Where do I sign in?

Use the HTTPS panel address provided for your own installation, in the form https://YOUR_SERVER_IP:PORT/admin. No local installation is needed on the device you browse from. SSH access remains available for initial setup and private connections. Your account, application, dashboard and SQLite history are on your server. This website has no shared customer login or dashboard.

Which systems can I use it on?

The x86-64 installer accepts Ubuntu 22.04 / 24.04 / 26.04 LTS and Debian 12 / 13. Ubuntu 24.04 has fresh preview.5 installation and trusted-IP certificate validation; the others have isolated-userspace application checks, not full OS/service/certificate tests. See the current validation matrix. No ARM64 or Windows server binary is published.

Is the application open source?

Yes. The free edition is available on GitHub under Apache License 2.0. You may use, modify and redistribute it under that license, including independent installations on multiple servers. Third-party components and media retain their own licenses. Optional AI provider fees are paid by the user.
