A careful start.
A clear direction.

Metric Owl is in active development. This page separates the working preview from the features still on the way.

In the current preview

  • English web control center with dark and light themes.
  • Live CPU, memory, network, disk and process measurements.
  • Local SQLite history with progressive summaries and event evidence.
  • Ready-made rule packs, editable thresholds and time windows.
  • Installer-created administrator credentials and optional two-factor authentication with a local QR code; keyed setup remains available for manual installs.
  • Public-IP HTTPS browser access configured by the guided installer, with private local/SSH access retained.
  • Local and SSH stdio MCP access with separate, revocable client keys.
  • Connection screens for optional AI, email reports and signed webhooks.

Platform validation

The same installer locally detects Ubuntu 22.04 / 24.04 / 26.04 LTS or Debian 12 / 13 on x86-64. Detection does not upload a machine inventory. ARM64 and Windows server binaries are not published.

  • Ubuntu 24.04: the exact anonymous GitHub command for v0.1.0-preview.5 passed a fresh installation on a real server. The service started, a trusted IP certificate was issued on port 8443, and a username/password account was created without a domain, setup key or required MFA. External HTTPS browser sign-in, live data and chart rendering passed. A certificate-renewal dry run against Let’s Encrypt staging also succeeded; existing hosted-site configuration, certificates and checked routes were preserved.
  • Ubuntu 22.04 / 26.04 and Debian 12 / 13: the static musl binary passed fresh-account creation, password sign-in, SQLite and real-metric reads with email disabled in isolated userspaces sharing an Ubuntu 24.04 kernel. These are not full OS, systemd, firewall or certificate-installation tests.
  • Apple Silicon macOS: local development/application checks only; no public installer package.

What we’ve exercised

The application has run on Apple Silicon macOS and Ubuntu 24.04 x86-64. Local tests cover authentication, rule boundaries, history aggregation and an actual SSH MCP connection to an Ubuntu test instance. These checks do not establish every target platform or long-term production workload as supported.

The screenshots on this website show the actual application interface with synthetic, non-sensitive example data. They are not a public connection to an owner’s machine.

The distributed Ubuntu uninstaller passed while preserving the test account and history. A second fresh GitHub installation selected port 9443 when 8443 was occupied; trusted HTTPS, password sign-in, live CPU and SSE passed, and the existing 8443 listener remained untouched.

Fresh SSH MCP checks passed for server information, current readings and aligned CPU/RAM history; restricted scopes and revoked access were rejected, with no AI requests made.

Additional preview checks

  • Restart notifications after a server comes back online.
  • TLS certificate expiry checks and richer HTTP checks.
  • Scheduled-job and backup completion monitoring.
  • More Linux pressure, disk I/O and capacity signals.
  • Readable hosted-domain and service discovery.

These checks are implemented in the public preview and are undergoing release acceptance. No public production release is implied.

Later, with Pro

Multiple-server management, independent full-host outage monitoring and team workflows are planned. There is no Pro purchase or subscription offering yet.

Public preview · v0.1.0-preview.5

The source and Ubuntu / Debian x86-64 release are available on GitHub. The GitHub installer prepares HTTPS access on your own public IPv4 address at an available panel port (8443 by default); no domain or central account is required. Optional two-factor authentication uses a QR code generated locally in your browser.

Official preview binaries are free under the binary license. The public source remains proprietary under the project license. Email can use your own SMTP provider; a central notification relay is optional. Direct SMTP inbox delivery has not been tested for this preview.
