Install once.
Open anywhere.

Three steps to your own server dashboard. No app to install on the computer or phone you view it from.

You need Ubuntu or Debian x86-64 with a public IPv4 address. No domain or cloud account required. Versions and validation →

  1. 01

    Run one command on your server.

    Paste this into your server’s terminal. The installer and application package come directly from GitHub. Your OS is detected locally; no machine inventory is uploaded.

    Install Metric Owl
    curl -fsSL https://raw.githubusercontent.com/SpeakQuery/metric-owl/v0.1.0-preview.5/scripts/bootstrap-linux.sh | sudo bash
  2. 02

    Answer the installer.

    Follow the HTTPS prompts, choose an administrator username, and enter your password twice. The installer prints your panel address when it finishes.

    For example: https://YOUR_SERVER_IP:PORT/admin

  3. 03

    Open your panel and sign in.

    Open the printed address in any browser. Sign in with the username and password you just chose. That’s it — your live dashboard is ready.

    No setup key or authenticator app is required. You can add optional two-factor authentication later in Security & system.

Your server. Your dashboard.

Your application, dashboard, account, metrics and SQLite history run on your own server. No central cloud account is needed. Optional AI, email, MCP and webhooks share selected data only when you enable them.

The installer selects port 8443, or 9443 / 10443 if occupied, and prints the exact URL. Port 80 for Metric Owl certificate validation and the selected panel port must be reachable. Network details →

Uninstall: sudo bash /usr/share/doc/server-guard/uninstall-linux.sh — your account and history are retained. Removal details →
