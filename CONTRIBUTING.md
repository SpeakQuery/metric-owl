# Contributing to Metric Owl

Contributions to the free, self-hosted edition are welcome. Start with a focused
issue or pull request describing the problem and the intended behavior. For local
setup and checks, see [Development](docs/DEVELOPMENT.md).

## Keep changes easy to review

- Keep the dashboard, user messages and documentation in English.
- Preserve read-only monitoring and bounded, scoped MCP access.
- Include relevant tests and describe what you verified; distinguish local checks
  from real operating-system installation or email-delivery evidence.
- Use synthetic examples. Never commit credentials, runtime databases, personal
  server data or private logs. Report security issues through [Security](.github/SECURITY.md).
- Keep dependency and media license notices with any added third-party material.

## Contribution license

Unless you explicitly state otherwise, contributions intentionally submitted for
inclusion in this repository are provided under the same [Apache License 2.0](LICENSE)
as the free edition. You retain your copyright. No separate contributor license
agreement or copyright assignment is required. Submit only material you have the
right to contribute, and identify any third-party licensing terms.

Pro fleet-management and team features are planned for a separate repository and
are not part of the current free-edition contribution scope.
