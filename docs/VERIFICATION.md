## Actual Ubuntu 24.04 x86-64 installation (October 31)

Built Rust 1.99.1 on the owner's Ubuntu 24.04 machine under a separate unprivileged
build account, one build job at nice 15. Real agent/relay integration passed on
Linux, including full synthetic 24-hour history, setup lifecycle and scope/revocation.
Installed the release as the restricted `server-guard` systemd service. Observed:
loopback-only port 4877; initial owner setup remains unconfigured; approximately
15.2 MiB service cgroup memory at one point (not a performance benchmark).

The configuration digest of existing Nginx/Apache/certificate files matched before
and after installation. The original Nginx master PID stayed unchanged. No web-server
reload, domain/certificate edits, firewall changes or public monitoring port were made.

A separate disposable systemd test instance ran the same installed binary. A client
on the Mac connected through **SSH stdio**, initialized official MCP, read real
Ubuntu inventory/current CPU and RAM and actual available history, then verified
key revocation. It observed four cores and approximately 15.6 GiB RAM. Only one real
history bucket existed during that short smoke test; no claim of pre-install history
is made. The temporary key, account, data and unit were removed. The owner's installed
account was not created or changed. Evidence: `artifacts/validation/ubuntu-ssh-mcp.json`.

A single separately authorized email was submitted directly from Ubuntu to the
owner's specified address through the recipient's published MX. Existing Python
stdlib SMTP was used; no mail client, MTA or package was installed. STARTTLS succeeded
and the receiving SMTP server accepted the message. Inbox delivery is **not yet
verified**. This one-off SMTP test is not evidence that the product notification
relay/Postmark account has been provisioned. Evidence: `ubuntu-email-test.json`.

The full-host outage heartbeat proposal has been deferred to Pro. Restart detection
and the newly accepted P0/site-discovery features are tracked in `NEXT_FEATURES.md`;
this installation evidence does not claim those subsequent changes are deployed.
